## 模块一：东方智慧（5讲）

### 第1讲：孔子与儒家 — 「仁」的千年回响

**学习目标：**
- 理解「仁」的核心含义及其在现代社会的应用
- 掌握儒家「修齐治平」的思维框架
- 能用苏格拉底式问答与孔子对话

**核心智者：** 孔子（前551-前479）、孟子（前372-前289）、荀子（前313-前238）

**思想地图：**
```
孔子 → 仁义礼智信 → 内圣外王
  ├── 孟子：性善论 → 仁政 → 民贵君轻
  └── 荀子：性恶论 → 礼法并重 → 化性起伪
```

**核心概念：**
- **仁**：爱人，推己及人。「己所不欲，勿施于人」
- **礼**：社会秩序与行为规范。「克己复礼为仁」
- **中庸**：不偏不倚，过犹不及
- **知行合一**（王阳明发展）：知是行之始，行是知之成

**经典对话练习：**
> 问孔子：「如何在现代社会中践行仁？」
> 孔子风格：不直接回答，用反问引导思考

**📝 练习题：**
1. **概念辨析**：「仁」和「爱」有什么区别？为什么孔子不用「爱」而用「仁」？
2. **现代应用**：在职场中，如何用「己所不欲，勿施于人」处理同事关系？
3. **思想对比**：孟子的「性善论」和荀子的「性恶论」，你更认同哪个？为什么？
4. **实践挑战**：记录一周内你践行「仁」的3个具体事例

**💬 讨论问题：**
- 如果孔子生活在2026年，他会如何看待社交媒体？
- 「礼」在现代社会是否还有意义？它的现代形式是什么？
- 儒家的「等级秩序」与现代「平等」观念是否矛盾？

**🤖 Digital Sage 对话提示：**
```
请在 Digital Sage 中选择「孔子」，问他：
「我想成为一个更好的人，但现代社会太复杂了，您会怎么建议我？」
观察孔子如何用反问引导你思考。
```

**阅读推荐：** 《论语》（难度：中）、《孟子》（难度：中）

### 第2讲：老子与道家 — 「无为」的最高境界

**学习目标：**
- 理解「无为」不是不作为，而是不妄为
- 掌握道家「反者道之动」的辩证思维
- 能用道家智慧处理压力和焦虑

**核心智者：** 老子（春秋）、庄子（前369-前286）

**思想地图：**
```
老子 → 道法自然 → 无为而治
  └── 庄子 → 逍遥游 → 齐物论 → 物我两忘
```

**核心概念：**
- **道**：万物本源，不可言说。「道可道，非常道」
- **无为**：不是不作为，而是不妄为，顺势而为
- **柔弱胜刚强**：水善利万物而不争
- **齐物论**（庄子）：万物平等，是非相对
- **逍遥游**（庄子）：精神自由的最高境界

**经典对话练习：**
> 问庄子：「什么是真正的自由？」
> 庄子风格：用寓言和比喻，从具体到抽象

**📝 练习题：**
1. **概念辨析**：「无为」和「懒惰」的区别是什么？
2. **寓言解读**：解释「庖丁解牛」的三层含义（技术→道→养生）
3. **现代应用**：在「内卷」的社会中，道家的「无为」如何帮助你？
4. **思想实验**：如果你是庄子，你会如何回应「你为什么不追求功名？」
5. **实践挑战**：尝试一天「无为」——不主动争取，观察会发生什么

**💬 讨论问题：**
- 老子的「小国寡民」理想与现代全球化是否矛盾？
- 庄子的「齐物论」是否意味着没有是非标准？
- 道家思想如何帮助解决现代人的焦虑？

**🤖 Digital Sage 对话提示：**
```
请在 Digital Sage 中选择「庄子」，问他：
「我每天都很焦虑，总觉得自己不够好，您能用一个寓言开导我吗？」
观察庄子如何用故事而非说理来回答。
```

**阅读推荐：** 《道德经》（难度：高）、《庄子》（难度：高）

### 第3讲：王阳明心学 — 知行合一的实践哲学

**学习目标：**
- 理解「心即理」的哲学含义
- 掌握「致良知」的实践方法
- 能用「事上磨练」处理实际问题

**核心智者：** 王阳明（1472-1529）

**思想地图：**
```
朱熹 → 格物致知 → 理在物中
王阳明 → 心即理 → 致良知 → 知行合一
```

**核心概念：**
- **心即理**：理不在外部事物中，而在自己心中
- **致良知**：人人都有良知，关键是去除遮蔽
- **知行合一**：真知必能行，知而不行是未知
- **事上磨练**：在实际事务中修炼心性

**📝 练习题：**
1. **概念辨析**：「知行合一」与「言行一致」有什么区别？
2. **案例分析**：你知道应该早睡但总是熬夜，用王阳明的框架分析原因
3. **实践挑战**：面对一个道德困境，用「致良知」的方法做决策：
   - 静坐，回归本心
   - 问自己：「我的良知告诉我什么？」
   - 去除私欲遮蔽
   - 立即行动
4. **思想对比**：王阳明的「心即理」与笛卡尔的「我思故我在」有何异同？

**💬 讨论问题：**
- 王阳明被贬到龙场悟道，苦难对他的思想有什么影响？
- 「致良知」是否过于主观？如何避免自欺？
- 王阳明的思想对现代创业者有什么启发？

**🤖 Digital Sage 对话提示：**
```
请在 Digital Sage 中选择「王阳明」，问他：
「我知道很多道理，但总是做不到，您说这是为什么？」
观察王阳明如何用「知行合一」的框架回答。
```

**阅读推荐：** 《传习录》（难度：中）

### 第4讲：墨子与法家 — 功利主义与制度设计

**学习目标：**
- 理解墨子「兼爱」与儒家「仁爱」的区别
- 掌握韩非子「法术势」的制度设计思维
- 能用制度思维解决团队管理问题

**核心智者：** 墨子（前468-前376）、韩非子（前280-前233）

**思想地图：**
```
墨子 → 兼爱非攻 → 尚贤尚同 → 功利主义先驱
韩非子 → 法术势 → 以法治国 → 制度设计
```

**核心概念：**
- **兼爱**：无差别地爱所有人（vs 儒家的有差等之爱）
- **非攻**：反对侵略战争
- **法术势**（韩非子）：法=法律制度，术=统治技巧，势=权力地位
- **人性假设**：墨子重功利，韩非子重自利

**与西方对照：**
- 墨子的「兼爱」≈ 边沁的功利主义
- 韩非子的「法术势」≈ 马基雅维利的《君主论》

**📝 练习题：**
1. **思想辩论**：如果你是国王，你会用儒家还是法家治理国家？为什么？
2. **现代应用**：墨子的「兼爱」如何应用于国际关系？
3. **制度设计**：用韩非子的「法术势」框架设计一个团队管理制度
4. **案例分析**：商鞅变法为什么成功了？又为什么商鞅本人被车裂？

**💬 讨论问题：**
- 墨子的「兼爱」在现实中可行吗？
- 法家的「人性本恶」假设是否过于悲观？
- 现代法治与韩非子的「以法治国」有何本质区别？

**🤖 Digital Sage 对话提示：**
```
请在 Digital Sage 中选择「韩非子」，问他：
「我是一个团队领导，如何设计制度让团队高效运转，而不是靠个人魅力？」
观察韩非子如何用「法术势」框架回答。
```

**阅读推荐：** 《墨子》（难度：中）、《韩非子》（难度：中）

### 第5讲：孙子与鬼谷子 — 东方战略智慧

- **纵横术**（鬼谷子）：说服、谈判、联盟的艺术

**📝 练习题：**

4. **思想对比**：孙子的「兵者诡道」与商业诚信是否矛盾？

**💬 讨论问题：**
- 孙子兵法是否适用于个人职业发展？
- 鬼谷子的「揣摩之术」是否过于算计？

## 模块二：西方哲学（5讲）

### 第6讲：苏格拉底方法 — 提问的艺术

**学习目标：**
- 掌握苏格拉底式问答的方法
- 理解「无知之知」的智慧
- 能用提问引导他人思考

**核心智者：** 苏格拉底（前469-前399）

**核心方法：**
- **苏格拉底式问答**：不给答案，用问题引导思考
- **反讽**：假装无知，揭示对方的自相矛盾
- **产婆术**：帮助他人「生出」真理，而非灌输
- **无知之知**：知道自己不知道，是智慧的开始

**对话模板：**
```
用户：什么是正义？
苏格拉底：你说你追求正义，那我问你——一个人对自己朋友诚实，对敌人欺骗，这算正义吗？
用户：应该算吧？
苏格拉底：那如果朋友做了坏事，你帮他隐瞒，这也是正义吗？
```

**📝 练习题：**
1. **对话练习**：用苏格拉底方法讨论「什么是成功？」（至少5轮问答）
2. **自我反思**：你最近一次改变观点是因为什么？是被说服还是自己想通的？
3. **现代应用**：在团队讨论中，如何用苏格拉底方法引导共识？
4. **思想实验**：如果苏格拉底活在今天，他会在社交媒体上如何发言？

**💬 讨论问题：**
- 苏格拉底为什么宁愿赴死也不逃跑？
- 「无知之知」与「自信」是否矛盾？
- 苏格拉底方法在教育中是否仍然有效？

**🤖 Digital Sage 对话提示：**
```
请在 Digital Sage 中选择「苏格拉底」，问他：
「什么是幸福？」
注意：苏格拉底不会直接回答，他会用反问引导你思考。
```

**阅读推荐：** 《苏格拉底的申辩》（难度：易）

### 第7讲：柏拉图与亚里士多德 — 理念与现实

**学习目标：**
- 理解柏拉图「理念论」与亚里士多德「经验论」的区别
- 掌握「四因说」的分析框架
- 能用两种思维方式分析同一问题

**核心智者：** 柏拉图（前428-前348）、亚里士多德（前384-前232）

**思想对比：**
| 维度 | 柏拉图 | 亚里士多德 |
|------|--------|------------|
| 本体论 | 理念世界是真实的 | 现实世界是真实的 |
| 认识论 | 回忆说 | 经验观察+逻辑推理 |
| 方法论 | 从抽象到具体 | 从具体到抽象 |
| 政治 | 哲学王统治 | 中产阶级共和 |

**核心概念：**
- **洞穴寓言**（柏拉图）：我们看到的只是影子，真实在洞穴之外
- **四因说**（亚里士多德）：质料因、形式因、动力因、目的因
- **中庸之道**（亚里士多德）：美德是两个极端之间的中间状态

**📝 练习题：**
1. **思想实验**：用「洞穴寓言」解释为什么有些人拒绝接受新观念
2. **四因分析**：用亚里士多德的「四因说」分析一部手机
3. **现代应用**：柏拉图的「哲学王」与现代民主制度有何关系？
4. **思想对比**：在教育中，应该先教抽象概念还是先教具体案例？

**💬 讨论问题：**
- 柏拉图的「理念世界」是否类似于数学中的「完美图形」？
- 亚里士多德的「中庸」是否意味着避免极端？
- 两位哲人的思想如何影响了西方科学传统？

**🤖 Digital Sage 对话提示：**
```
请在 Digital Sage 中选择「亚里士多德」，问他：
「如何判断一个决定是否正确？请用您的四因说框架分析。」
```

**阅读推荐：** 《理想国》（难度：高）、《尼各马可伦理学》（难度：高）

### 第8讲：康德与启蒙理性 — 人是目的

**学习目标：**
- 理解「绝对命令」的道德原则
- 掌握「人是目的」的伦理框架
- 能用康德的方法做道德决策

**核心智者：** 康德（1724-1804）

**核心概念：**
- **绝对命令**：「你的行为准则应该能成为普遍法则」
- **人是目的**：永远把人当作目的，而非仅仅是手段
- **先验哲学**：我们认识世界的方式受限于我们的认知结构
- **二律背反**：理性在某些问题上会自相矛盾

**经典思想实验：**
> 如果对一个杀手说谎能救一个无辜的人，这在道德上是否正确？
> 康德的回答：说谎在任何情况下都是错误的——因为如果每个人都说谎，社会信任将崩溃。

**📝 练习题：**
1. **道德决策**：用「绝对命令」分析「是否应该举报朋友的违规行为」
2. **思想实验**：如果每个人都能读取他人想法，社会会变得更好还是更差？
3. **现代应用**：在AI伦理中，「人是目的」原则如何应用？
4. **思想对比**：康德的「绝对命令」与功利主义（最大多数人的最大幸福）有何冲突？

**💬 讨论问题：**
- 康德的道德哲学是否过于严格？
- 「人是目的」在商业中是否可行？
- 康德的「先验哲学」如何影响了现代认知科学？

**🤖 Digital Sage 对话提示：**
```
请在 Digital Sage 中选择「康德」，问他：
「为了公司利益，我是否可以对客户隐瞒一些信息？」
观察康德如何用「绝对命令」框架回答。
```

**阅读推荐：** 《道德形而上学奠基》（难度：高）

### 第9讲：尼采与存在主义 — 上帝死了之后

**学习目标：**
- 理解「上帝死了」的哲学含义
- 掌握存在主义的核心思想
- 能用存在主义视角面对人生困境

**核心智者：** 尼采（1844-1900）、萨特（1905-1980）、加缪（1913-1960）

**思想演进：**
```
尼采：上帝死了 → 重估一切价值 → 超人哲学 → 权力意志
萨特：存在先于本质 → 绝对自由 → 绝对责任
加缪：世界是荒诞的 → 反抗 → 在荒诞中寻找意义
```

**核心概念：**
- **超人**（尼采）：超越传统道德，创造自己的价值
- **永恒轮回**（尼采）：如果人生会无限重复，你还会这样活吗？
- **存在先于本质**（萨特）：人没有预设的本质，通过选择定义自己
- **荒诞**（加缪）：人对意义的渴望与世界的沉默之间的矛盾

**📝 练习题：**
1. **思想实验**：用「永恒轮回」审视你当前的生活——你愿意无限重复吗？
